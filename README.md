**Space Origin** adalah game arkade *sci-fi shoot 'em up* (shmup) berbasis web yang menantang. Sebagai pilot terakhir dari armada bumi, tugas Anda adalah bertahan hidup dan menghancurkan invasi armada UFO misterius di luar angkasa. Rasakan pertempuran sengit yang menuntut refleks cepat dan strategi taktis!

---

## 🌌 Fitur Utama

Game ini dilengkapi dengan berbagai mekanik modern yang membuat gameplay terasa imersif dan adiktif:

* **Responsive Layout & Fullscreen Mode:** Mainkan dengan nyaman di PC maupun HP. Mendukung mode otomatis *fullscreen* sekali klik saat menekan tombol Start untuk menyembunyikan bar browser.
* **Dynamic Enemy Waves:** Musuh tidak monoton! Semakin tinggi skor Anda, pergerakan musuh akan semakin cerdas, mulai dari pola lurus, gerakan zigzag (sinusoidal), hingga musuh elit yang mengejar posisi Anda.
* **Epic Mini-Boss Battles:** Bersiaplah menghadapi armada raksasa setiap kelipatan skor tertentu. Lengkap dengan sistem **Telegraphing Laser** (garis pandu tipis aba-aba sebelum bos menembak) yang menuntut kejelian Anda untuk menghindar.
* **Tactical Gameplay Mechanics:** * **Energy Shield:** Perisai regeneratif yang melindungi HP utama Anda jika berhasil menghindar dari serangan selama beberapa detik.
    * **EMP Shockwave:** Kemampuan khusus untuk membekukan (*stun*) seluruh musuh dan proyektil di layar saat terdesak.
    * **Drop Power-Ups:** Ambil kapsul dari sisa ledakan musuh untuk mendapatkan efek *Shield*, *Double Shot*, atau *Rapid Fire*.
* **Immersive Dynamic Audio:** Menggunakan Web Audio API untuk efek suara dramatis. Musik latar akan melambat saat darah kritis dan berubah menjadi efek teredam (*muffled*) saat layar *Game Over* muncul.

## 🎮 Cara Bermain

### Kontrol PC:
* **Bergerak:** Gunakan `W, A, S, D` atau `Tombol Panah`.
* **Menembak:** `Spasi` (Spacebar).
* **EMP Shockwave:** Tekan `E`.

### Kontrol Mobile / HP:
* **Bergerak:** *Drag & slide* pada layar untuk mengarahkan pesawat.
* **Menembak:** Otomatis (*Auto-fire*).
* **EMP Shockwave:** Tombol virtual khusus di layar UI.

## 🛠️ Teknologi yang Digunakan

* **Core:** HTML5, CSS3 (Custom styling & animation effects)
* **Logic & Rendering:** JavaScript (HTML5 Canvas / Vanilla JavaScript)
* **Audio Engine:** Web Audio API untuk manipulasi suara yang dinamis

## 🚀 Cara Menjalankan Game Secara Lokal

Ingin mencoba atau mengembangkan game ini di perangkat Anda sendiri? Ikuti langkah mudah berikut:

1.  **Clone Repositori Ini:**
    ```bash
    git clone [https://github.com/USERNAME_ANDA/space-origin.git](https://github.com/USERNAME_ANDA/space-origin.git)
    ```
2.  **Masuk ke Direktori Project:**
    ```bash
    cd space-origin
    ```
3.  **Jalankan Game:**
    * Cukup buka file `index.html` langsung di browser Anda, atau
    * Gunakan ekstensi seperti *Live Server* di VS Code untuk pengalaman pengembangan yang lebih baik.
