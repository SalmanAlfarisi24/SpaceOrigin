# 🚀 Space Origin: Galactic Strike

[](https://www.google.com/search?q=https://github.com/salman-alfarisi/space-origin)
[](https://hamzanwadi.ac.id/)
[](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

**Space Origin** adalah sebuah game 2D side-scrolling shooter bertema sci-fi yang dikembangkan menggunakan **JavaScript** dan **Three.js/HTML5 Canvas**. Pemain berperan sebagai pilot pesawat tempur luar angkasa yang harus bertahan hidup dari serangan gerombolan alien di planet Xylos-9.

> Proyek ini disusun sebagai tugas GameJam

-----

## 🎮 Fitur Utama

  * **Dynamic Background:** Efek *parallax scrolling* luar angkasa yang memberikan kesan kedalaman saat terbang.
  * **Combat System:** Sistem menembak dengan laser neon lengkap dengan efek *Muzzle Flash*.
  * **Particle Effects:** Efek ledakan (*splash*) menggunakan sistem partikel bawaan saat alien berhasil dihancurkan.
  * **Difficulty Scaling:** Kecepatan dan jumlah kemunculan musuh yang terus meningkat seiring bertambahnya skor.

## 🛠️ Tech Stack

  * **Language:** JavaScript (ES6+)
  * **Engine/Library:** Three.js / Typescript/  HTML5 Canvas API
  * **Styling:** CSS3 (Sci-Fi HUD Design)

-----

## 🕹️ Cara Bermain

| Kontrol | Aksi |
| :--- | :--- |
| **W / A / S / D** | Manuver Pesawat |
| **Space Bar** | Menembak Laser |
| **P** | Pause Game |
| **R** | Restart (saat Game Over) |

## 🚀 Menjalankan Game Secara Lokal

1.  **Clone repositori ini:**
    ```bash
    git clone https://github.com/username-kamu/space-origin.git
    ```
2.  **Masuk ke direktori:**
    ```bash
    cd namafolder/space-origin
    ```
3.  **Jika menggunakan IDE:**
    ```bash
    npm install
    npm build
    npm run dev
    ```
    jalankan perintah satu per satu
4.  **Jalankan dengan Live Server:**
    Karena game ini memuat aset eksternal (gambar & suara), disarankan menggunakan ekstensi **Live Server** di VS Code agar fitur audio dan tekstur tidak terblokir oleh kebijakan CORS browser.
